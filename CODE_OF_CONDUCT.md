# Code of Conduct

We are committed to a welcoming, inclusive, and respectful community.

## Standards
- Be respectful and considerate.
- Use inclusive language.
- Accept constructive feedback gracefully.
- Focus on what benefits the project and community.

## Unacceptable Behavior
- Harassment or discrimination of any kind.
- Trolling, insults, or personal attacks.
- Publishing others’ private information without permission.

## Scope
This applies to all project spaces and public spaces when representing the project.

## Enforcement
Report issues via GitHub issues or by contacting the maintainers. Actions may include warnings or removal from the community.
