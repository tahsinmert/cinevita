# Contributing to CineVita

Thanks for your interest in contributing!

## Setup
1. Fork and clone the repo
2. Install deps: `npm i`
3. Create `.env.local` (see README)
4. Run dev: `npm run dev`

## Workflow
- Create feature branches from `main`
- Keep PRs small and focused
- Include screenshots for UI changes
- Add tests where relevant

## Commit Messages
- Use conventional prefixes: `feat`, `fix`, `docs`, `refactor`, `chore`
- Example: `feat: add rounded movie cards with hover slide`

## Code Style
- TypeScript, strict where possible
- Tailwind for styles; avoid inline styles when utilities exist
- Prefer accessibility: semantic elements, alt text, focus states

## Security
- Do not commit secrets
- Report vulnerabilities privately (see `SECURITY.md`)
